DualPair per Windows
====================

Sistema i problemi del dual boot con Linux. Per ora: l'orario.

Linux legge l'orologio hardware in UTC, Windows in ora locale: per questo, dopo aver
usato Linux, l'ora di Windows è sbagliata. "Usa UTC" fa leggere anche a Windows
l'orologio in UTC (valore RealTimeIsUniversal=1 nel registro): è la soluzione standard.

Come si usa
1. Estrai la cartella dove vuoi (per esempio in Documenti).
2. Doppio clic su DualPair.cmd e rispondi Sì alla richiesta di amministratore.
3. Premi "Usa UTC (consigliato con Linux)".
4. Se in DualPair su Linux avevi scelto "Linux in ora locale", rimetti Linux in UTC
   dalla scheda Orario.

Per tornare come prima: "Torna all'ora locale".

Se Windows blocca DualPair.cmd: clic destro sul file > Proprietà > spunta
"Annulla blocco" > OK.
